    AlphaSun 声波分析仪 · 说明与免责声明

    当前版本 v2.12.0（build 20261002） · 作者：阳光 net2net2net（VX：net2net）· 主要组件：Web Audio API / Canvas / Electron / Capacitor。
    顶部链路图示：🎙️ 声波采集 → 🔧 信号预处理 → 📊 特征提取 → 🧠 分类解码 → 📝 后处理输出，采集运行时逐级点亮，说明每一条结论从哪一步来。
    二级分析台录制：单次上限 180 秒（到点自动停止并生成音频）；主采集已在运行时复用同一路麦克风，不再另开第二路输入；停止录制后不对整段录音做全量解码（波形直接取自实时采样），以避免移动端内存溢出闪退。
    全部计算本地完成（Web Audio API），不上传音频。参数中心点击任意参数可查看介绍 / 实时值 / 历史曲线（本地内存缓存）。
    声纹登记为离线启发式指纹，仅存本机 localStorage，非生物识别级。
    标注纠正样本（自举标注）仅存本机 IndexedDB，可一键导出 JSON，用于后续离线算法改进，绝不上传。
    内置判别模型为离线启发式、非训练模型：动物 / 禽鸟 / 交通工具 / 自然环境的识别结果是基于频谱形状（分段能量、质心、平坦度、通量、周期性）的启发式匹配，不是物种分类器，可能严重误判，仅供参考；已针对「牛哞 / 马嘶」假阳性做硬否决治理（实测 12 类无关声源不再误报），但马蹄与脚步 / 节拍敲击在单帧频谱上本质同形，无法可靠区分。
    曲目识别需联网且默认关闭，当前版本不上传原始音频，也不输出臆造的歌名 / 歌手。
    语音转写依赖浏览器内置 SpeechRecognition（Chrome + 网络）。
    需在 https / localhost / file:// 安全上下文授权麦克风。
