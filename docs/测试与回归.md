# AlphaSun 声波分析仪 · 测试与回归

> 原则：**崩溃与功能失效必须在交付前由脚本查出，不能等用户运行才发现。**
> 「不崩溃」不等于「功能正常」——新增指标必须验证**真的出数**。

## 一、日常自检（改动后必跑）

```bash
node tools/check.js
```

覆盖 5 道关，任一失败即退出码 1：

| # | 检查 | 说明 |
|---|---|---|
| 1 | `validate.js` | JS 引用的 DOM id 全部存在（210 个）、E 映射覆盖（159 key）、五点版本一致、无陈旧版本残留 |
| 2 | 内联脚本语法 | `vm.Script` 编译全部内联 `<script>` |
| 3 | `tools/algo-selftest.js` | 从 **index.html 源码真身**抽取算法验算：A/C 计权 vs IEC 61672-1 标称值、BPM 命中与拒绝 |
| 4 | 三处源码一致性 | 根目录 / `www/` / `android public/` 的 index.html md5 必须相同（防版本漂移） |
| 5 | 离线资源完整性 | `assets/lame.min.js` 存在且被 `sw.js` 缓存清单收录 |

## 二、真实环境回归（Electron + 虚拟麦克风）

```bash
# 全链路：录制 → 声谱图 → 背景分离 → 降噪 → 人声提取 → 保存五格式
NODE_PATH="C:/Users/net2n/.workbuddy/binaries/node/workspace/node_modules" \
  env -u ELECTRON_RUN_AS_NODE REC_SEC=8 node tools/pw-electron-test.js

# 新增指标是否真的出数（不是「不崩溃却恒显示 —」）
NODE_PATH=... env -u ELECTRON_RUN_AS_NODE SEC=20 node tools/pw-metrics-check.js

# FLAC 产物用 Chromium 自带解码器校验
NODE_PATH=... env -u ELECTRON_RUN_AS_NODE FILE=<abs.flac> node tools/pw-flac-edge.js
```

`REC_SEC` 控制录制时长；`SKIP_SPEC=1` 可跳过声谱图（快速回归）。

## 四、踩过的坑（**别再踩**）

1. **必须 `env -u ELECTRON_RUN_AS_NODE`**：WorkBuddy 的 bash 与 PowerShell 会话都全局注入该变量，
   Electron GUI 会变成纯 Node **静默退出**（无窗口、无崩溃日志）。
2. **`_electron.launch` 必须显式 `executablePath`**，且**不要传 `env` 覆盖**（传空 `ELECTRON_RUN_AS_NODE` 仍失败）。
3. **Electron 僵尸进程**会让后续 launch 持续报 `Target page, context or browser has been closed`。
4. **Portable 单文件 EXE 无法被 Playwright 驱动**：回归用 `main.js`，产物用 `asar list` / 启动冒烟验证。
5. **`page.evaluate` 读不到主世界的 `let`/`const` 顶层声明**（连一直存在的 `BANDS` 都读不到）。
   需要内部状态时改用 **MutationObserver 统计 DOM 更新次数** 或把值挂到 DOM/window。
6. **Edge 下 `file://` 加载媒体元素一律 `error`**（file 源是 opaque），不是文件不合法 → 走本地 HTTP 服务再验。
7. **Electron 不触发 Playwright 的 `download` 事件** → 拦截 `HTMLAnchorElement.prototype.click` 拿 blob URL。
8. **算法自检要从源码抽，不要抄副本**：抄一份来测 = 测的不是线上代码。用花括号配平截取（正则抗不住 `  }}` 结尾）。
9. **低频计权点的取样误差不是公式错误**：1024bin @48kHz = 23.4Hz/格，31.5Hz 只能落在 bin1(23.4Hz)。
   自检低频段改用 8192bin 细表，免得把方法学局限误报成实现缺陷。
10. **同一文件的多处编辑必须串行**，改完 grep 复读关键标记（工具回报 success ≠ 改动生效）。

## 五、发布流程

```bash
node tools/check.js                    # 1. 自检全绿
node tools/bump-version.js x.y.z       # 2. 升版本（五点同步）
node sync-www.js && node tools/cap-copy.js   # 3. 同步三处源码
node tools/check.js                    # 4. 再自检（第 4 步校验一致性）
# 5. 构建
env -u ELECTRON_RUN_AS_NODE npx electron-builder --win portable --linux tar.gz
cd android && env -u ELECTRON_RUN_AS_NODE ./gradlew assembleRelease
# 6. 归档
node cleanup-dist.js                   # APK 入位（含内容版本校验）+ 旧产物退场
# 7. 记录 md5 到 CHANGELOG / 工作日志；追加 CHANGELOG 条目
```
